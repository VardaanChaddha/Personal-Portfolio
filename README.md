# Personal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript
(no frameworks, no build step) — designed around a "blueprint / technical
drawing" visual concept: grid-paper backgrounds, registration marks, and a
footer styled like an engineering drawing title block.

## Files

- `index.html` — page structure (header/nav, hero, about, projects, contact, footer)
- `style.css` — design tokens, layout, responsive breakpoints (900px / 700px / 480px)
- `script.js` — mobile nav, scroll-spy, scroll reveal, hero typewriter, contact form
- `documentation.pdf` — the file linked from the footer's "Download Documentation" button

## Run it locally before pushing

No build step needed — just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
